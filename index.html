Under The Hood

Enterprise-grade security. Zero servers to maintain.

Most platforms find out they're vulnerable after something goes wrong. Ours already went through that fight — every rule, every login, every payment is protected by architecture that's been tested against real attacks, not just written on a whiteboard and hoped for.

Authentication
Firebase Authentication with mandatory email verification before any account can post or appear publicly.
Database Security
Least-privilege Firestore rules on every collection — admin-only paths, owner-only paths, participant-only game and message access — enforced server-side, not just hidden in the interface.
Security-First Development
Every database rule and access path is reviewed against real attack patterns before it ships — security is verified during development, not discovered after the fact.
Bot & Abuse Protection
App Check (reCAPTCHA v3) verifies every request comes from your real app before it ever reaches your database.
File Storage
Owner-only writes, file size and type restrictions, and default-deny on anything not explicitly permitted.
Rate Limiting
Message limits, invite cooldowns, and resubmission limits are enforced inside the database rules themselves — a modified client can't bypass them, because the check never happens client-side alone.
Content Moderation
Banned-word filtering and automatic contact-info detection block phone numbers, emails, and links from posts and messages before they're ever saved.
Payment Security
Stripe webhook signature verification, supporting multiple independent signing secrets — API keys are stored in Secret Manager and never touch application code.
Disaster Recovery
Daily automated Firestore backups (30-day retention), daily Auth account exports (30-day retention, stored where no client-side code can ever read them), and Storage file versioning (90-day retention) — plus a written recovery runbook covering database loss, account loss, a single missing file, or losing the entire project.
Credential Hygiene
Repository access is secured through Git Credential Manager rather than embedded tokens — nothing sensitive lives in plain text in the codebase.
Quality Assurance
A real, browser-based automated test suite exercises the entire platform end-to-end — including live two-player games — before any update ships.
